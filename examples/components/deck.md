# How a report is made

1. **Choose data**

   Raw cases or curated indicators
2. **Transform**

   Standard methods, applied once
3. **Design**

   Content and delivery
4. **Render** {.accent}

   Code and HTML, generated
5. **Publish**

   Disseminated and archived

{as=steps reveal=items .fade-right @0}

Formatting is preconfigured; review and approval stay explicit. {.callout @+ .fade-up}
