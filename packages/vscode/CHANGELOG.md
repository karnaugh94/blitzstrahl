# Changelog

The blitzstrahl extension's own versions. It runs the blitzstrahl a project
installs (1.1 or later), which has its own changelog.

## [0.1.0]

- Preview beside the markdown, on `blitzstrahl dev`, following the cursor
  from slide to slide; or in the browser (`blitzstrahl.preview.where`).
- `check`'s findings in the Problems panel, on save or as you type
  (`blitzstrahl.check`).
- Completion and hover for keys and values in frontmatter and in `chart`,
  `map` and `embed` blocks, from blitzstrahl's JSON Schemas.
- Snippets for render blocks, containers, components and notes.
- Commands: Preview, Open in Browser, Check (network included), Present,
  Export PDF.
